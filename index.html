Yaparr for Linux

Serverless peer-to-peer chat. This is the Flatpak repository of Yaparr.

Install it (the 64-bit Intel/AMD and ARM versions are both here):

flatpak install https://flatpak.yaparr.com/com.yaparr.Yaparr.flatpakref

It then updates with the rest of your software, or with flatpak update. To add the repository by itself:

flatpak remote-add --if-not-exists yaparr https://flatpak.yaparr.com/yaparr.flatpakrepo
