# Notifications

## Notifications

**Notify me of messages** notifies you of direct messages and of mentions and replies to you. In a room's menu you can turn on every message for that room. The lock screen shows who wrote and where, never the words.

## Staying connected in the background

**Stay connected in the background** keeps Yaparr connected when you leave it, so messages arrive and notify. Android shows a notification while it is on, and it uses some battery. **Let Yaparr run in the background** asks Android not to stop Yaparr to save power.

If you use [Yaparr Cloud](yaparr-cloud.md#push-notifications), a push can wake the phone instead, without it staying connected all the time.
