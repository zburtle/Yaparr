# Updates

An update is downloaded from Yaparr's releases on GitHub, which sees your device's address, and is checked against the checksum published with it before it is used.

On Android, you are asked to confirm before it is installed, and Android only accepts a package signed with the same key as the app. On a computer, Yaparr is closed and replaced when you accept.

Turn **Look for updates when Yaparr opens** off and nothing is contacted until you choose **Check for updates**. See [Installer and updates](../installer-and-updates.md) for how it is built.
