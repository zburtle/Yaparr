# Backlog

What is left to do is tracked as [GitHub issues](https://github.com/zburtle/Yaparr/issues), one per piece of work, so each can be discussed, linked from a pull request (`Closes #123`) and closed when it is done. Finished work is described in the [documentation](docs/README.md).

How to find things:

- **By area:** filter by an `area:` label: [security](https://github.com/zburtle/Yaparr/labels/area%3A%20security), [moderation](https://github.com/zburtle/Yaparr/labels/area%3A%20moderation), [voice](https://github.com/zburtle/Yaparr/labels/area%3A%20voice), [soundboard](https://github.com/zburtle/Yaparr/labels/area%3A%20soundboard), [relaying](https://github.com/zburtle/Yaparr/labels/area%3A%20relaying), [devices](https://github.com/zburtle/Yaparr/labels/area%3A%20devices), [screen sharing](https://github.com/zburtle/Yaparr/labels/area%3A%20screen%20sharing), [streams](https://github.com/zburtle/Yaparr/labels/area%3A%20streams), [network tests](https://github.com/zburtle/Yaparr/labels/area%3A%20network%20tests), [android](https://github.com/zburtle/Yaparr/labels/area%3A%20android), [flatpak](https://github.com/zburtle/Yaparr/labels/area%3A%20flatpak), [desktop app](https://github.com/zburtle/Yaparr/labels/area%3A%20desktop%20app), [ci](https://github.com/zburtle/Yaparr/labels/area%3A%20ci).
- **By kind:** `bug`, `enhancement`, `research` (needs finding out before it can be built) and `tracking` (a list of smaller pieces, such as [Android](https://github.com/zburtle/Yaparr/issues/61)).
- **By size:** `size: small` (under a day), `size: medium` (a few days) and `size: large` (a week or more).

What does not work, or has not been proven, is in [Known limitations](docs/known-limitations.md).
