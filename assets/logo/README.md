# Yaparr logo

A parrot, because **yap** is talking and **arr** is both the pirate sound and the suffix of the torrent-adjacent tools (Sonarr, Radarr) that Yaparr's BitTorrent-DHT discovery nods to. The sound waves off the beak are the yapping, and echo the radar mark those tools use.

- `yaparr-icon.svg` is the square app icon and `yaparr-logo.svg` adds the wordmark.
- `yaparr.ico` and `png/` are made from the icon (16 to 512 px) and used by the desktop app, the MSI and the `.deb`. Regenerate them after changing the SVG by rendering it at each size with a browser.
- Colours: indigo `#4F6BED` (gradient `#6A84F5` to `#3A4FD0`), amber `#F2A93B` / `#E08A1E`, coral `#F0605F`, ink `#26306B`.
